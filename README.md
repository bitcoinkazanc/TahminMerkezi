# TahminMerkezi

Telegram Mini App tabanlı futbol maçları ve topluluk tahmin uygulaması.

## Özellikler

- Telegram Mini App
- Telegram kullanıcı doğrulaması
- Futbol maçları
- MS1 / MSX / MS2 tahminleri
- Tahmin güven oranı
- Maç analizi ve yorumları
- Topluluk sohbeti
- Kullanıcı profili
- Supabase veritabanı
- Supabase Realtime
- SportScore futbol verileri

## Teknolojiler

- Next.js
- React
- Supabase
- Telegram Mini Apps
- SportScore API
- Vercel
- GitHub
